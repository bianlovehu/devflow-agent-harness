# 第2版报告的修改和验证记录

日期：2026-11-11。范围是本地报告功能，发布封装仍然取消。报告内容、字段说明和规则见[报告怎么写，结论怎么核对](report-rules.md)。

## 已完成的修改

- 报告增加版本号，页面分别展示事实、推测、建议；建议不计为新增缺陷。
- 每项记录直接引用的原文、成立前提、未确认条件、严重程度依据及不同后果。
- 服务端根据实际工具记录填写采集完整性、读取范围、固定代码版本和知识库开关；缺少记录就显示未知。
- 短日志不能证明采集截断；未启用知识库不能证明空库；没有调用链不能填写系统层面可触发。
- 代码问题必须直接引用本次代码。当前安装日志与历史故障文档放在一起，也不能证明旧代码故障复发。
- 同一原因合并，保留不同后果与证据。旧报告仍能读取、引用和导出，新字段显示未知。
- 引用检查与结论复核分别记录。模型不能把自己的报告标成已通过复核。
