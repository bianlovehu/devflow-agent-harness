# Taskboard 架构说明

这是人工构造的演示工程，不对应真实生产系统。

## 数据和调用边界

任务记录包含 id、owner_id、title。服务通过 actor_id 识别当前用户，存储层返回的任务集合可能包含多个用户的数据。

list_tasks 负责在返回结果前按 owner_id 过滤。上层没有额外过滤，因此移除这一条件会改变访问边界。

## 可选标签契约

labels 字段允许缺省、空列表或 null；缺省与 null 均解释为空列表。非列表且非 null 的值应拒绝。

## 标题格式化

标题只影响展示。允许折叠连续空格，不改变任务归属或访问权限。
