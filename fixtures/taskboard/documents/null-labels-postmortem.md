# 可选标签处理回归复盘（人工构造）

## 现象

某次重构将 payload.get("labels") 的显式 null 检查，替换为 payload.get("labels", [])。

## 原因

dict.get 的默认值只在键缺省时使用；当请求明确包含 labels: null 时，取值仍是 None。随后遍历这一值会触发 TypeError。

## 验证

分别覆盖字段缺省、null、空列表、合法列表和非法字符串。缺省与 null 两类输入不能互相替代。

## 结论边界

本文是历史样例，不能代替对当前提交代码的检查；引用时需要与本次任务的 head_sha 对照。
